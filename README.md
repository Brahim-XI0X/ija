# مشروع ija — نسخة منظّمة + ميزة رفع الفيديوهات حسب الشعبة

## 1. ماذا تغيّر في التنظيم؟

الملفات كانت كلها بشكل مسطّح رغم أن الروابط الداخلية (`../config/db.php`,
`auth/login.php`, `student/...`, `teacher/...`) كانت تفترض بنية مجلدات معيّنة.
تم الآن وضع كل ملف في مكانه الصحيح:

```
ija/
├── index.php, about.php, contact.php   (صفحات عامة قبل تسجيل الدخول)
├── home.php, update.php                (بعد تسجيل الدخول)
├── config/
│   ├── db.php
│   └── sections.php                    (قائمة الشعب: Bac Info, Bac Sientifique...)
├── auth/
│   ├── login.php, register.php, logout.php
│   └── login_admin.php
├── admin/
│   ├── dashboard.php, allow_home.php, deny_home.php
│   └── delete_user.php, delete_message.php
├── student/
│   ├── about.php, contact.php, profile.php
│   ├── courses.php        ← كورسات شعبة الطالب فقط
│   └── watch-video.php    ← تشغيل الفيديوهات + تعليقات
├── teacher/
│   ├── teacher_profile.php
│   ├── add-course.php     ← إنشاء كورس مرتبط بشعبة
│   ├── add-video.php      ← رفع فيديو (الميزة الجديدة)
│   └── my-videos.php      ← إدارة/حذف فيديوهاته
├── css/, js/, images/
├── uploads/profiles/, uploads/videos/
└── database/
    ├── ija.sql                 (القاعدة الأصلية)
    └── schema_updates.sql      (التحديثات الجديدة، شغّلها بعد ija.sql)
```

### أخطاء تم تصحيحها بالمناسبة
- `update.php` كان يستعمل `$_SESSION` بدون `session_start()`.
- `login_admin.php` كان يطبع متغير `$error` غير معرّف عند أول تحميل للصفحة.
- `deny_home.php` كان يحتوي كوداً منسوخاً بالخطأ من صفحة اتصال كاملة بعد `exit;` (كود ميت لا يُنفَّذ لكنه كان يسبب فوضى).
- جدول `contacts` و`comments` و`videos` كانت مستخدمة في الكود لكن غير موجودة في `ija.sql` — أُضيفت في `schema_updates.sql`.
- الأعمدة `can_access_home` و`active_session` في `users` كانت مستخدمة في `home.php` لكن غير موجودة في `ija.sql` — أُضيفت أيضاً.

## 2. الميزة الجديدة: رفع فيديو من طرف الأستاذ حسب الشعبة

المبدأ:
1. **شعبة لكل طالب** (`students_profiles.section`) تُحدَّد عند التسجيل.
2. **شعبة لكل كورس** (`courses.section`) يحدّدها الأستاذ عند إنشاء الكورس.
3. **فيديو مرتبط بكورس** (`videos.course_id`) → وبالتالي مرتبط بشعبة تلقائياً.
4. الطالب لا يرى في `student/courses.php` و `student/watch-video.php` سوى الكورسات
   والفيديوهات التي تخص شعبته بالضبط (تحقق مزدوج في السيرفر، وليس فقط إخفاء بالواجهة).

خطوات الاستخدام:
- الأستاذ يسجّل دخول → **إنشاء كورس** (`teacher/add-course.php`) ويختار الشعبة المستهدفة.
- ثم **رفع فيديو** (`teacher/add-video.php`) لهذا الكورس (صيغ mp4/webm/ogg، حد أقصى 200MB).
- يمكنه إدارة/حذف فيديوهاته من `teacher/my-videos.php`.
- الطالب يفتح **الكورسات** (`student/courses.php`) فيرى فقط كورسات شعبته، ثم
  **يشاهد الفيديو** (`student/watch-video.php`) ويمكنه إضافة تعليقات.

## 3. التثبيت
1. استورد `database/ija.sql` في MySQL.
2. شغّل `database/schema_updates.sql` على نفس القاعدة.
3. عدّل بيانات الاتصال في `config/db.php` إذا لزم.
4. تأكد أن مجلدي `uploads/profiles` و `uploads/videos` قابلان للكتابة من طرف السيرفر.
5. أنشئ حساب أستاذ من `auth/register.php`، أنشئ كورساً، ثم أنشئ حساب طالب بنفس الشعبة لتجربة المشاهدة.

## 4. ملاحظة حول الملفات القديمة
بعض الملفات في المشروع الأصلي أصبحت غير ضرورية بعد إضافة هذا النظام الديناميكي
(`playlist1.php`, `playlist2.php`, `playlist3.php`, `playlist1c2.php`, `playlist1ex.php`,
`teachers.php`, `denyperson.php`, `subscrption.php`, `users.php`, `my-courses.php`,
`add-courses.php` القديم) لأن `student/watch-video.php` و `student/courses.php` الجديدين
يقومان بنفس الدور تلقائياً انطلاقاً من قاعدة البيانات. تم استبعادها من هذه النسخة.

## 5. المرحلة 2: XP/مستويات/شارات + اختبارات احترافية + شهادات PDF+QR

**⚠️ قبل التجربة:** شغّل `database/schema_v2_gamification_quizzes_certificates.sql` بعد
`schema_updates.sql` (بنفس طريقة تنفيذ SQL في phpMyAdmin).

### نظام XP / المستويات / الشارات
- الطالب يكسب **10 XP** عند إنهاء كل فيديو، و**30 XP** عند اجتياز أي اختبار.
- كل 100 XP = مستوى جديد (Level).
- سلسلة أيام الدراسة (Study Streak) تُحسب تلقائياً عند أي نشاط يومي (مشاهدة فيديو أو اجتياز اختبار).
- شارات تلقائية: أول فيديو، 10 فيديوهات، أول اختبار ناجح، 5 اختبارات ناجحة، 7 أيام متتالية، إتمام كورس كامل.
- `leaderboard.php`: ترتيب أفضل 50 طالباً حسب XP.

### لوحات التحكم
- `student/dashboard.php`: نسبة إكمال كل كورس، ساعات الدراسة، السلسلة، معدل الاختبارات، المواد
  التي تحتاج مراجعة (أقل من 60%)، الشارات المكتسبة.
- `teacher/dashboard.php`: عدد الطلاب، الأرباح **المقدَّرة** (السعر × عدد طلاب نفس الشعبة — لا توجد
  بوابة دفع فعلية في المشروع)، أكثر الفيديوهات مشاهدة، تحليل أداء الطلاب في اختباراته.

### الاختبارات الاحترافية
- المعلم: `teacher/quizzes/list.php` لإنشاء اختبار (مرتبط بكورس، مدة، نسبة نجاح)، و
  `teacher/quizzes/questions.php` لإضافة أسئلة اختيار من متعدد.
- الطالب: `student/quizzes.php` لعرض اختبارات شعبته، و `student/take-quiz.php` للاجتياز:
  - **مؤقت** عد تنازلي حقيقي (JS) يرسل الإجابات تلقائياً عند انتهاء الوقت.
  - **ترتيب عشوائي** للأسئلة والخيارات في كل محاولة.
  - **إجراءات أساسية ضد الغش** (وليست حلاً كاملاً): منع النقر بالزر الأيمن، منع النسخ/اللصق،
    رصد الخروج من التبويب (تحذير + إرسال تلقائي بعد 3 مرات).
  - عند النجاح: +30 XP، وفحص تلقائي لإصدار شهادة إن أكمل الطالب الكورس بالكامل.

### الشهادات
- تُصدر تلقائياً عند إنهاء كل فيديوهات الكورس **و** اجتياز اختباراته (إن وُجدت).
- `student/certificates.php`: قائمة شهادات الطالب.
- `student/certificate.php`: شهادة قابلة للطباعة/الحفظ كـ PDF (زر "طباعة" يستعمل خاصية الطباعة
  في المتصفح Print → Save as PDF، بدون أي مكتبة PDF خارجية) مع **رمز QR** حقيقي (عبر خدمة
  `api.qrserver.com` المجانية، يُحمَّل من متصفح الزائر مباشرة — لا يحتاج أي مفتاح API).
- `verify-certificate.php` (بالجذر): صفحة **عامة بدون تسجيل دخول** يفتحها أي شخص (صاحب عمل مثلاً)
  بمسح رمز QR أو إدخال رقم الشهادة يدوياً، للتحقق من صحتها.

## 6. الذكاء الاصطناعي (لم يُنفَّذ بعد — يحتاج مفتاح API)

لتفعيل مساعد ذكي / تلخيص تلقائي / توليد اختبارات / تصحيح بالذكاء الاصطناعي لاحقاً:
1. أنشئ حساباً في [OpenAI](https://platform.openai.com) أو [Anthropic Console](https://console.anthropic.com).
2. أنشئ مفتاح API (Settings → API Keys)، واحفظه في مكان آمن (لا تضعه أبداً في كود يُرفع لموقع عام).
3. عادة تُحاسَب حسب الاستعمال (Pay-as-you-go)، وليست مجانية بالكامل — تحقق من التسعير قبل الاستعمال المكثف.
4. بمجرد توفر المفتاح، يمكن ربطه بملف PHP عبر `curl` يرسل طلبات لـ API الخاص بالمزوّد.

أخبرني عندما يتوفر لديك مفتاح وسأبني التكامل الفعلي (المساعد الذكي أولاً، أو أي ميزة تفضّلها).
